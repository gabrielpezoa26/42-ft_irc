testes manuais pra rodar de vez em quando p ter ctz q nd quebrou rs

exemplo de teste:
	-> roda make run em um terminal, esse vai ser o terminal do servidor
	-> abre outro terminal e roda make nc, esse vai ser o terminal do client
	-> faz a mesma coisa em outro terminal
	-> entao vai ficar 1 terminal pro servidor, e 2 pra clients
	-> fzr o login com senha, nick e user nos 2 clients
	-> PRIVMSG <nick> <mensagem>
	-> no outro client, é pra aparecer a mensagem recebida 







exemplo de comando USER:
	USER gcesar-n 0 * :Gabriel
	
	gcesar-n         username
	0                "modo", o 0 é meio q o padrão
	*                o nome do server, tbm é meio que padrão
	:Gabriel         o nome real da pessoa
